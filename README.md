# livetoahundred

Public pages for [@livetoahundred](https://www.instagram.com/livetoahundred/): privacy policy, data deletion instructions and terms of service.

Live at https://cezugo.github.io/livetoahundred/

Edit the page bodies in `src/`, then run `python3 build.py` to regenerate the `index.html` files. Fonts (Oswald, Archivo) are self-hosted under the SIL Open Font License (`assets/fonts/OFL-*.txt`).
